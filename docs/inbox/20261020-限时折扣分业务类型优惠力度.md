# 限时折扣 · 分业务类型设置优惠力度 · 原始诉求

| 字段 | 内容 |
|---|---|
| 收件时间 | 2026-10-20 |
| 来源 | 产品口述 |
| 状态 | 已按正式后台 1:1 补上限时折扣活动；分业务类型优惠力度仍待澄清 |

## 诉求原文

新需求：限时折扣活动，参与商品的优惠力度支持分业务类型设置。

## 当前已知（对照现有促销后台，非正式结论）

- 正式产品有「限时折扣」活动类型；当前促销后台原型没有独立的限时折扣配置页。
- 已有活动（买1送N、会员价、满减/折、一口价等）的业务类型是活动级多选：勾选后整场活动在这些业务下生效，商品优惠力度不按业务拆开。
- 会员价已支持「逐商品」设置优惠力度（折扣 / 减价 / 固定价格），但仍是一套力度覆盖所选全部业务类型。

## 关键追问（澄清门禁）

1. 粒度：同一活动、同一商品，是否要为堂食、外卖、自提等各自填一套优惠力度？活动未勾选的业务类型是不参与，还是必须沿用一套统一力度？
2. 优惠形式：分业务时，折扣、减价、特价是否也能按业务各自选择，还是形式全活动统一、只拆数值？某业务留空时，顾客下该业务单是不享受本活动，还是回退到统一力度？
3. 存量与点餐：已上线的限时折扣是否保持「全业务同一力度」不变，仅新活动或编辑后才按业务拆？顾客下单时，是否严格按当前订单的业务类型取对应力度？
