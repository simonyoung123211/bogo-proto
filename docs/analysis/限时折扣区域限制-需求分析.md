# 限时折扣区域限制 · 需求分析

| 工作卡 | 当前记录 |
|---|---|
| 目标 | 品牌按合作点位投放商品折扣，支持一场活动覆盖多家门店的不同区域。 |
| 路径 | 跨门店基础资料、活动冲突和点餐资格，需用多店交叉样例验证。 |
| 确认决定 | 品牌建活动，区域归门店；按门店逐一求区域交集；任何冲突点均拦截整场正式保存。 |
| 当前产物 | [区域限制 PRD v1.9](../prd/限时折扣区域限制-PRD.md)，限时折扣本地原型。 |
| 验证 | [范围回归脚本](../../scripts/test-discount-areas.mjs)通过。浏览器走通新建、草稿、冲突修复、刷新回显和入口试算；列表发布、暂停启用会复查冲突，双标签页同时发布同一点位时仅一场成功。批量选择已验证整店勾选、跨店搜索全选、筛选外选择保留、跳过禁用项、取消回滚及确认后保存。 |
| 联调范围 | 当前目录和价格试算使用演示数据。上线前需接品牌门店区域目录、服务端冲突校验及小程序真实订单试算。 |

v1.2 已在浏览器验证参与门店页的点位明细与批量移除。跨店勾选后只移除对应门店的点位，弹窗和覆盖数同步更新，正式保存并刷新后明细一致。全选移除后会提示补选区域。

## 冲突交互复查（2026-11-20）

| 线上截图与 v1.8 的差异 | v1.9 原型处理 |
|---|---|
| 线上冲突卡有「去修改」，原型只能调整本活动。单店完全重叠时，原型缺少保留本活动覆盖的协作路径 | 按现有管理权限进入对方活动。处理后返回原提交页并重查全部冲突，未提交配置随流程保留 |
| 线上卡片标明创建人，对照表显示活动 ID 和归属。缺少这些信息时，同名活动难以区分，也难以请其他运营协助 | 摘要保留创建人与归属，明细提供状态和可复制的 ID。使用列表现有脱敏口径 |
| 线上对照表突出重叠列，名单在同一窗口下方。原型通过切换视图查看，重叠时段也只显示在时间行 | 起止时间交集与首个实际重叠时段分别展示。对照表可直达门店、点位和重叠商品 |
| 线上提交页直接展示排除前后范围。原型须先打开预览才能核对数字 | 首屏展示全部排除的覆盖变化。多场勾选、去重与排除后重算继续在预览内完成 |
| 已发布活动的通用时间和商品入口包含锁定项。存量活动变更后也缺少明确的复查出口 | 已发布活动优先展示门店与点位入口，时间入口直接定位到可编辑的活动周期。支持手动重新校验及从对方活动返回自动重查 |

截图提供入口、展示项与单场重叠样例。跳转后返回原进度、多场分批以及权限降级由本地原型验证，正式联调需核对实际账号权限。

沿用限时折扣可以复用无门槛、全部商品和统一力度。把区域放进参与范围，图书馆和网吧可在同一天享不同折扣。按品牌汇总区域会把不同门店的同名点位误判为冲突。

本期按本次订单携带的区域判断。合作码与装修入口若实际指向同一门店区域，适用同一限制。若要求仅扫码有效，需另外识别入口来源。区域优惠限制开启时，已勾选的优惠类型才可用。
