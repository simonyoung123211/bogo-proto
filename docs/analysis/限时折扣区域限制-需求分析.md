# 限时折扣区域限制 · 需求分析

| 工作卡 | 当前记录 |
|---|---|
| 目标 | 品牌按合作点位投放商品折扣，支持一场活动覆盖多家门店的不同区域。 |
| 路径 | 跨门店基础资料、活动冲突和点餐资格，需用多店交叉样例验证。 |
| 确认决定 | 品牌建活动，区域归门店；按门店逐一求区域交集；任何冲突点均拦截整场正式保存。 |
| 当前产物 | [商家配置、区域批量选择与移除及订单匹配规则 v1.2](../prd/限时折扣区域限制-PRD.md)，限时折扣本地原型。 |
| 验证 | [范围回归脚本](../../scripts/test-discount-areas.mjs)通过。浏览器走通新建、草稿、冲突修复、刷新回显和入口试算；列表发布、暂停启用会复查冲突，双标签页同时发布同一点位时仅一场成功。批量选择已验证整店勾选、跨店搜索全选、筛选外选择保留、跳过禁用项、取消回滚及确认后保存。 |
| 联调范围 | 当前目录和价格试算使用演示数据。上线前需接品牌门店区域目录、服务端冲突校验及小程序真实订单试算。 |

v1.2 已在浏览器验证参与门店页的点位明细与批量移除。跨店勾选后只移除对应门店的点位，弹窗和覆盖数同步更新，正式保存并刷新后明细一致。全选移除后会提示补选区域。

沿用限时折扣可以复用无门槛、全部商品和统一力度。把区域放进参与范围，图书馆和网吧可在同一天享不同折扣。按品牌汇总区域会把不同门店的同名点位误判为冲突。

本期按本次订单携带的区域判断。合作码与装修入口若实际指向同一门店区域，适用同一限制。若要求仅扫码有效，需另外识别入口来源。区域优惠限制开启时，已勾选的优惠类型才可用。
